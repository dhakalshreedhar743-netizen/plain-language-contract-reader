## Project Overview
Plain-Language Contract Reader helps users understand complex legal agreements in simple language.

## Features
- Contract upload
- Simple-language summaries
- Key risk identification
- Important clause highlighting
- User-friendly interface

## Tools Used
- Figma
- UI/UX Design
- Wireframing
- Prototyping
